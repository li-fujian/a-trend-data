# 本机通达信增量更新

用户已明确选择通达信本地数据优先、频繁增量维护。实现独立 Python 入口，不依赖 Java、其他项目或行情网络接口。

## 选择

- 采用：`.day` 日线 + 本机 `gbbq` 计算等比前复权，统一到现有 JSON 数据接口。
- 不采用：每次全市场联网核对，耗时取决于外部接口且引入不同复权口径。
- 不采用：把原始日线直接标记为前复权，除权后历史价格口径会错误。

## 流程

首次保留旧缓存作为不可变的历史基准并备份；基准日之后由本地日线与除权记录延续更新。更早历史不冒充本地重算结果，以元数据说明来源。以后使用源文件状态、内容指纹和每个标的的有效除权记录判断：无变化跳过；仅追加且无新除权则增量；发生除权或历史改写则仅重算对应文件。除权记录解码按内容缓存，修改时间不作为日期门禁。

默认范围：本机 A 股日线、六个主要指数以及已有且本机存在的缓存。缺少来源或格式异常逐个报告，不启动联网兜底，也不阻断其它正常文件。个股成交量保持原始股数，指数原始手数换为股；复权不调整实际成交量。

写入临时文件后原子替换；替换前保存原文件。单实例锁避免并发写入。状态清单用于加速；历史基准文件必须保留。首次接入时本机约五年的日线可衔接更早的缓存历史；后续源日期回退或文件缩短时保留缓存并报告。基准日之前的除权记录修订、基准日价格修订或基准文件缺失，逐个报告并保留原数据。

## 验收

单元覆盖二进制格式、现金分红/送股/配股/扩缩股、非交易日事件、未来事件、成交量、普通追加、历史修订、除权变更、断点重跑及无变化零改写。真实数据完成一次本地更新，再运行一次测量无变化耗时和零联网行为。

## 格式参考

- [GBBQ 记录布局与解码](https://github.com/rainx/pytdx/blob/master/pytdx/reader/gbbq_reader.py)
- [除权字段与类别](https://github.com/rainx/pytdx/blob/master/pytdx/parser/get_xdxr_info.py)
- [等比前复权参考公式](https://github.com/mootdx/mootdx/blob/master/mootdx/tools/reversion.py)：本实现保留真实成交量，不进行成交量复权。

计算口径：每 10 股现金分红 `cash`、送转 `bonus`、配股 `rights`、配股价 `price`，理论除权参考价为 `(昨收*10-cash+rights*price)/(10+bonus+rights)`；用参考价/昨收作为历史价格乘数，并连乘至文件末日。扩缩股类别 11 使用股数倍数的倒数；类别 12 为非流通股缩股，不单独调整交易价格。字段常量为公开协议数据，来源见解码模块。
